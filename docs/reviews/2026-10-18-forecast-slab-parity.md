## Change and contract

Both live CastForecasts renderers now call engine-free helpers for their actual local line segments and mesh-reuse decision. The helpers use the existing outline/tessellation gate. Rendering still applies core-to-engine coordinates, world position, heading, cosmetic lift, stroke width and color in the existing adapter.

One shared, hand-specified fixture checks lower and upper perimeters, inner holes, open versus committed direction markers, thin/zero-thickness slabs, center-height markers, invalid bounds, unknown contact and the tessellation ceiling. Each implementation checks all segment endpoints against that fixture. Reuse cases cover local bounds, shape/dimensions, commitment and eligibility changes; translation with matching world bounds and heading-only changes keep the same local geometry. Null coverage removes meshes. Style remains fixed for a renderer's lifetime, as before. The comparison is by values, so JSON key ordering and body-unused center tolerance no longer cause redundant rebuilding; rendered geometry is unchanged.

This implements the existing [forecasting contract](../design/cast-forecasting.md), including its reusable geometry and body-slab clauses. No skill IDs, collision rules, generated protocol, production content or world transforms changed. Existing all-shape 2D fixtures remain enabled; the new paired fixture is additional 3D local segment evidence, not another collision implementation.
